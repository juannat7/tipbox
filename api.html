API reference¶

Choose the operation first. All public imports below work from the installed package; examples use T time points, D observable columns, and N independent trajectories.

API at a glance¶

Task

Import or method

Contract

Simulate

model.make_trajectory(n, noise=..., seed=...)

TrajectoryResult: time (T,), observations (T,D), forcing (T,), noise scale, and metadata.

Build a labeled batch

tipbox.datasets.generate_dataset

BenchmarkDataset: observations (N,T,D), labels (N,), time and forcing (N,T), metadata per row.

Compute a window statistic

tipbox.indicators.rolling_*

One scalar signal (T,) becomes an aligned NumPy array (T,); warm-up, skipped, and invalid windows are NaN.

Score a trend

tipbox.metrics.kendall_tau

One indicator series becomes one Kendall tau-b score; undefined trends are NaN.

Evaluate scores

tipbox.metrics.binary_roc

Binary labels plus one score per trajectory become a BinaryRocResult with AUROC and coverage counts.

Evaluate several indicators

tipbox.metrics.ensemble_roc

A mapping of indicator series or scalar scores becomes an EnsembleRocResult; larger scores mean tipping.

Plot ROC curves

tipbox.metrics.plot_roc

Returns a Matplotlib Axes. Undefined curves remain in the result and are omitted from the plot.

Load observations

tipbox.datasets.load_empirical or load_microcosm_original

EmpiricalRecord: time (T,), observations (T,D), and source/sampling metadata. No class labels are inferred.

See Classical warning indicators for statistic definitions, Benchmarks and AUROC for batch controls and metric signatures, and Empirical records for source/cache controls. For an end-to-end example, start with Quickstart.

Discover and configure a model¶

from tipbox import get_system_info, list_systems

print(list_systems())
model = get_system_info("b_harvesting").create_model()
print(model.state_names, model.observable_names)
print(model.get_parameters())

get_parameters() exposes resolved configuration values. model.config is the immutable typed configuration. A parameter override belongs in the constructor; integration, sampling, noise, seed, and custom forcing belong in make_trajectory. The model collection links equations, units, defaults, and constructor examples.

References, missingness, and failures¶

  • n counts returned samples, including the initial state. Batch num_timesteps counts retained pre-reference samples.

  • initial_state and innovations use the model’s state/noise dimensions, which can differ from its observable dimension. Ricker uses a log-population state; its observed column is population.

  • locate_transition returns a reference index, or None when the requested reference is absent. A null reference is a comparison point. State-jump and forcing-crossing references have distinct meanings.

  • Use fixed integer windows for streaming. Nonfinite observations invalidate the whole window; they are not dropped or imputed. A skipped endpoint is distinct from a computed statistic equal to zero.

  • ROC requires both binary classes in the supplied labels. Missing scores are excluded with counts. If retained scores lose a class, AUROC is NaN and the curve is empty. plot_roc raises ValueError if no curve is defined.

  • Invalid dimensions or controls raise TypeError or ValueError. Exhausted batch rejection sampling raises RuntimeError with rejection counts. Empirical network failures propagate; unavailable offline files raise FileNotFoundError and checksum mismatches raise ValueError.

Array outputs can be converted with numpy.asarray. For strict JSON, convert nonfinite indicator values to null and select the metadata fields you need; NaN is meaningful analysis output, not a zero-valued measurement.

make_trajectory(n=None, *, dt=None, dt_sample=None, noise=0.01, initial_state=None, seed=0, innovations=None, null_simulation=False, param_end_multiplier=1.1, forcing=None)¶

Integrate exactly n observations from the configured start time.

Parameters:

  • n (int or None, default=None) – Number of returned samples, including the initial state; at least 2. None uses the configured start/end interval and output spacing. An explicit n overrides the configured end time.

  • dt (float or None, default=None) – Integration step. Defaults to config.dt, or config.dt_inner for AMOC. For Ricker this is the interval represented by one discrete map update.

  • dt_sample (float or None, default=None) – Output spacing; a positive integer multiple of dt. Defaults to 1.0 for MayHarvesting, RosenzweigMacArthur and SEIRx, 0.0005 for Thermoacoustic, and config.dt for the remaining models.

  • noise (float, default=0.01) – Nonnegative noise-strength parameter, with the same meaning as sigma_tilde in simulate. The model reference gives its exact diffusion formula; saddle-node uses an intensity and other models a multiplier. Zero disables process noise, but does not disable random initial states.

  • initial_state (array-like or None, default=None) – Initial model state in the order of model.state_names. Ricker uses log population, and Thermoacoustic uses pressure and scaled velocity. None uses the model’s sampler. A scalar is accepted for 1D models.

  • seed (int, default=0) – Local random seed; global random state is never changed.

  • innovations (array-like or None, default=None) – Standard-normal increments shaped (n_integration_steps, noise_dimension). These replace random increments and are multiplied by the model’s per-step scale. The physical and observed dimensions can differ.

  • null_simulation (bool, default=False) – Select the model’s null forcing schedule. This is a forcing choice, not a guarantee that the simulated state remains non-tipping.

  • param_end_multiplier (float, default=1.1) – For duration-normalized bifurcation ramps, the ratio of total duration to ramp duration. Rate schedules retain their absolute time origin.

  • forcing (callable or None, default=None) – Optional forcing(t) evaluated on the complete integration grid. It must return one finite scalar per time point, including RK4 midpoints, in the model’s forcing units.

Returns:

Observations, time, forcing and per-step noise scale. Metadata includes the resolved parameters and sampled physical state trajectory.

Return type:

TrajectoryResult

Raises:

ValueError – If the time grid is not finite and strictly increasing at the active JAX precision. Adjust the clock origin or step, or enable 64-bit mode.

Notes

Increasing n extends the time interval at fixed output spacing. The ecological bifurcation schedules normalize their ramp to that duration, so trajectories with different n are not generally prefixes of one another. Analytic critical parameters follow the model coefficients. AMOC uses an explicitly calibrated marker that must be reconsidered after changing its physical parameters. This method validates concrete arrays eagerly; use the low-level JAX kernels or legacy simulate method for autodiff.

class tipbox.types.TrajectoryResult(time, trajectory, param_values, sigma, metadata)¶

Time, observed state, forcing, per-step noise scale, and provenance.

make_trajectory always returns observations shaped (n_time, n_observables). The historical generate interface retains each model’s original shape. sigma is the standard deviation of an integration-step noise increment, including the square root of the integration step for continuous-time models. Discrete maps report their per-update state-noise scale instead.

Parameters:

  • time (Array)

  • trajectory (Array)

  • param_values (Array)

  • sigma (float | Array)

  • metadata (dict[str, Any] | None)

Historical generation interface¶

New code can use the model and batch APIs above. The established entry point remains available with its original context-buffer conventions; see Historical compatibility before comparing earlier experiments.

tipbox.generate.generate(key, tipping_type='b_harvesting', null_simulation=False, num_timesteps=500, steps_before_transition=1, buffer_size=1000, dt_sample=None, sigma_tilde=0.01, max_attempts=100, **generate_kwargs)¶

Return a full simulation, a pre-transition segment, and its metadata.

Parameters:

  • key (jax.Array) – Independent JAX random key for the simulation and any retries.

  • tipping_type (str, default="b_harvesting") – Named system from tipbox.registry.list_systems().

  • null_simulation (bool, default=False) – Request a non-tipping trajectory using the model’s null forcing.

  • num_timesteps (int, default=500) – Number of samples in the extracted segment.

  • steps_before_transition (int, default=1) – Number of samples excluded before the model’s transition marker.

  • buffer_size (int, default=1000) – Additional simulation context. Its effect on physical duration is model-specific; fixed-duration rate models retain their own time grid.

  • dt_sample (float or None, default=None) – Bifurcation-model output interval. None keeps the model’s default (1.0 for ecological models; 5.0 years for AMOC). Rate models sample on their configured dt grid and reject this argument.

  • sigma_tilde (float, default=0.01) – Model-specific noise scaling, interpreted by the model’s simulator.

  • max_attempts (int, default=100) – Maximum number of independent simulations before reporting rejection.

  • **generate_kwargs – Arguments passed to the model simulator, including initial_state, noise, and a typed config. Unsupported names raise TypeError.

Returns:

Two tipbox.types.TrajectoryResult objects and metadata. transition_index refers to the full trajectory. Null trajectories use a model-defined reference marker rather than an observed event.

Return type:

full, segment, info

Raises:

  • ValueError – For an unknown system or invalid requested lengths.

  • RuntimeError – If every simulation is rejected or lacks the requested context.
