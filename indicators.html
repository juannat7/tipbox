Classical warning indicators¶

Choose one scalar observable before analysis. For example, the first observation column of MayHarvesting is population density:

from tipbox.models import MayHarvesting
from tipbox.indicators import rolling_ar1, rolling_variance

result = MayHarvesting().make_trajectory(1000, seed=42)
population = result.trajectory[:, 0]
ar1 = rolling_ar1(population, window=200, detrend="linear")
variance = rolling_variance(population, window=200, detrend="linear")

The functions accept concrete NumPy or JAX arrays and return NumPy arrays of the same length. They are eager analysis routines, rather than JAX-transformable integration kernels. Their definitions follow the classical comparisons in kews. TipBox adds explicit missing-data handling and population moments.

Window preparation and statistics run in bounded batches. Long records do not materialize the complete window matrix; computational work still grows with the number and length of windows. Definitions, missingness rules, and trailing alignment are preserved; floating-point roundoff can depend on batch shape.

Windows and defaults¶

  • window=0.5 uses half the input length, rounded down. An integer such as 200 means samples; a float in (0, 1] means a fraction. 1.0 selects the full series, while the integer 1 is invalid. At least two samples are required, with additional lag requirements below. A one-ULP correction at integer boundaries makes window=0.29 select 29 out of 100 samples.

  • step=1 evaluates every complete trailing window. step=5 evaluates the first complete window and every fifth window thereafter. Every result is aligned to its window’s last observation. Warm-up and skipped positions are NaN.

  • detrend=None uses raw observations. detrend="linear" fits an intercept and slope separately inside each window, then analyzes the residuals. No full-series smoothing is applied. Later observations cannot change earlier output values when using a fixed integer window.

  • Any NaN or infinite observation invalidates its entire window. The functions never drop observations or join across a gap. Constant finite windows have zero variance and undefined normalized statistics (NaN).

Computations first translate each window by its first value to avoid spurious moments for decimal-valued constants. After linear detrending, a residual whose maximum magnitude is at most eight float64 machine epsilons times the translated window’s maximum magnitude is treated as numerical zero. This prevents fitting roundoff from becoming a warning signal on an exactly linear input.

Windows and lags count samples. These statistics assume equally spaced observations: a lag of one has a fixed physical duration only on a regular grid. For irregular empirical records, state and justify a resampling policy before using autocorrelation. Analyze separate experimental recovery segments separately. Choose any resampling, detrending, window, and indicator direction using training data or prior knowledge before evaluating held-out labels.

Definitions¶

For the \(w\) observations \(z_i\) in a window (or their detrended residuals), define \(\bar z=w^{-1}\sum_i z_i\) and \(m_p=w^{-1}\sum_i(z_i-\bar z)^p\).

For lag \(\ell\), construct \(u=z_{0:w-\ell}\) and \(v=z_{\ell:w}\) and center each paired vector separately. Writing \(S_{uv}=\sum_i(u_i-\bar u)(v_i-\bar v)\), the AR slope is \(S_{uv}/S_{uu}\), while the Pearson correlation is \(S_{uv}/\sqrt{S_{uu}S_{vv}}\). A nonzero denominator is required. The AR slope can exceed \([-1,1]\). The correlation differs from an ACF estimated using a shared full-window mean and variance, so specify the convention when comparing implementations.

These classical signals need not increase before every transition, especially for rate-induced tipping. Skewness also depends on the sign of the chosen observable. Inspect the physics and predeclare score directions rather than flipping indicators after seeing their test AUROC.

The population skewness and kurtosis conventions match SciPy’s skew(bias=True) and kurtosis(bias=True).

API¶

Classical early-warning statistics on trailing windows of one scalar signal.

All functions return a NumPy array aligned with the input. Warm-up samples and windows containing nonfinite observations are NaN. Each window uses observations through its endpoint; linear detrending is fitted within that window. For streams, use an integer window: fractional windows depend on the full input length. These eager analysis functions accept NumPy and concrete JAX arrays.

tipbox.indicators.rolling_acf(data, window=0.5, *, lag=1, step=1, detrend=None)¶

Trailing Pearson correlation of the two lagged, separately centered vectors.

This uses sqrt(Sxx * Syy) in the denominator; it is not the full-window autocovariance divided by the full-window variance. Require at least two pairs and nonzero variance in both vectors; undefined correlations are NaN. Arguments share the meanings in rolling_ar1().

tipbox.indicators.rolling_ar1(data, window=0.5, *, lag=1, step=1, detrend=None)¶

Trailing lagged OLS slope with an intercept, default lag=1 (AR1).

Regress x[t] on x[t-lag] inside each window, centering each paired vector separately. This slope can exceed [-1, 1]. Require at least two pairs and nonzero predictor variance; undefined slopes are NaN. lag is a sample count, not a physical-time interval. The window, step and detrend arguments have the same meanings as in rolling_variance().

tipbox.indicators.rolling_kurtosis(data, window=0.5, *, excess=True, step=1, detrend=None)¶

Trailing population kurtosis, without bias correction.

excess=True (default) returns m4 / m2**2 - 3, whose Gaussian limit is zero. excess=False returns Pearson kurtosis, whose Gaussian limit is three. Constant windows are undefined (NaN). Other arguments share the meanings in rolling_variance().

tipbox.indicators.rolling_skewness(data, window=0.5, *, step=1, detrend=None)¶

Trailing population skewness m3 / m2**1.5, without bias correction.

Constant windows have undefined skewness (NaN). Window, step and detrend arguments have the same meanings as in rolling_variance().

tipbox.indicators.rolling_variance(data, window=0.5, *, ddof=0, step=1, detrend=None)¶

Trailing variance; ddof=0 gives the population variance.

Parameters:

  • data (array-like, shape (n,)) – One scalar signal, sampled at regular intervals. Analyze separate recovery segments separately; no interpolation or missing-value removal is applied.

  • window (int or float, default=0.5) – Integer sample count or float fraction of the input length, rounded down.

  • ddof (int, default=0) – Variance denominator is window_size - ddof. Require 0 <= ddof < window_size.

  • step (int, default=1) – Evaluate every step-th window, starting with the first complete window. Unevaluated output positions remain NaN.

  • detrend (None or "linear", default=None) – Subtract a least-squares line fitted within each window, or use raw values.

Returns:

Values at the right edge of each evaluated window; NaN elsewhere. Constant finite windows have variance zero.

Return type:

numpy.ndarray, shape (n,)

tipbox.indicators.window_size(n, window)¶

Resolve a window to samples: integer count, or float fraction in (0, 1].

Fractions are rounded down, allowing one floating-point step at integer boundaries (e.g. 0.29 * 100). Require at least two samples and at most n. In particular, 1 is a one-sample count (invalid), while 1.0 selects the full series. Noninteger absolute counts such as 10.5 are invalid.

Parameters:

  • n (int)

  • window (float)

Return type:

int
