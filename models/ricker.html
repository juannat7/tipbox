Stochastic Ricker population map¶

Ricker implements a density-dependent population map in log-population coordinates. It is a reusable simulation component for population-decline studies such as the Daphnia sim-to-real case discussed in Daphnia and thermoacoustics. Its defaults are illustrative; they are not fitted Daphnia coefficients.

from tipbox.models import Ricker

result = Ricker(density_dependence=0.002).make_trajectory(500, noise=1, seed=42)
population = result.trajectory[:, 0]

Equations and coordinates¶

With population \(N_k=\exp(z_k)>0\), density coefficient \(b>0\), and independent standard-normal \(\xi_k\), each update is

\[\begin{split}z_{k+1} &= z_k+r_k-b\exp(z_k)+\sigma\,\eta\,\xi_k,\\ N_{k+1} &= N_k\exp(r_k-bN_k+\sigma\,\eta\,\xi_k).\end{split}\]

Here \(\eta\) is the noise argument (shared default 0.01) and \(\sigma\) is the configured log-growth amplitude (default 0.2). noise=1 therefore gives log-growth standard deviation 0.2 per update. There is no \(\sqrt{dt}\) factor: this is a discrete map. result.sigma is the per-update log-state scale \(\sigma\eta\).

The stored state and initial_state override are log population; the observed column is population. Without an override, initialization uses log(config.initial_population). A zero initial population has no finite log coordinate. No integer rounding, additive observation error, demographic Poisson sampling, extinction threshold, or clipping is applied. Positive populations approach zero continuously; a recorded zero caused by floating-point underflow is not a modeled extinction event.

At constant deterministic \(r\), the positive equilibrium is \(N^*=r/b\) for \(r>0\). Its map multiplier is \(1-r\), so it is locally stable for \(0<r<2\). The zero-population branch exchanges stability at \(r=0\); larger positive growth rates can produce other Ricker dynamics. This log-coordinate implementation follows the population dynamics for positive states but cannot represent the zero branch as a finite state.

Time, forcing, and markers¶

dt assigns a time interval to one map update. Changing it changes the number of updates per unit time; it is not an ODE refinement setting. dt_sample defaults to the configuration’s dt and may be an integer multiple of the update spacing. No conversion from model time to Daphnia days is inferred.

Forced log growth decreases linearly from r_start to r_end over the simulated duration divided by param_end_multiplier (default 1.1), then remains capped. Null forcing is constant r_null. As for other normalized ramps, changing n changes the forcing rate unless a custom callable is given. The classifier tests whether growth reaches or falls below zero; the positive reference is its first such sample. The null reference is the temporal midpoint. These are growth/bifurcation references, not observed extinction times.
