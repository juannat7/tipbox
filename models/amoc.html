Atlantic meridional overturning circulation¶

b_amoc and r_amoc · tipbox.models.AMOC and AMOCRate

Both classes accept a nested AMOCPhysics configuration. Table names such as physics.K_N identify fields on that object:

from tipbox.models import AMOC, AMOCPhysics

physics = AMOCPhysics(K_N=1.762e6)  # Gyre transport in m^3/s; the default.
model = AMOC(physics=physics, sigma_SN=1e-4)

Changing physical coefficients requires reconsidering the calibrated fold marker. Constructor keywords such as sigma_SN control the simulation configuration; nested physical coefficients belong in AMOCPhysics.

Both scenarios use the same two-state reduction of a five-box ocean model. The physical coordinates \(z_N,z_T\) are scaled salinity anomalies: \(S_N=S_0+z_N/100\) and \(S_T=S_0+z_T/100\). Absolute salinity in psu is \(1000S_0+10z\). Negative anomaly coordinates are physically permitted.

Transport and salt conservation¶

Write \(n=z_N/100\), \(u=z_T/100\), \(s=S_S-S_0\), and \(b=S_B-S_0\). The Indo-Pacific anomaly follows from conserved total salt:

\[i=\frac{C-S_0\sum_j V_j-V_Nn-V_Tu-V_Ss-V_Bb}{V_{IP}}.\]

Transport \(q\) in cubic metres per second and the observed strength \(Q\) in Sverdrups are

\[q=\frac{\lambda_q[\alpha(T_S-T_0)+\beta(n-s)]} {1+\lambda_q\alpha\mu},\qquad Q=10^{-6}q.\]

The freshwater transports use the hosing control \(H\):

\[F_N(H)=10^6(F_{N0}+F_{NH}H),\qquad F_T(H)=10^6(F_{T0}+F_{TH}H).\]

Define the advective terms

\[\begin{split}A_N&=\begin{cases}q(u-n),&q\ge0,\\|q|(b-n),&q<0,\end{cases}\\ A_T&=\begin{cases}q[\gamma s+(1-\gamma)i-u],&q\ge0,\\|q|(n-u),&q<0.\end{cases}\end{split}\]

Then the implemented stochastic salt balance is

\[\begin{split}dz_N&=\frac{100Y}{V_N}[A_N+K_N(u-n)-F_NS_0]dt +\eta\sigma_{SN}\,dW_N,\\ dz_T&=\frac{100Y}{V_T}[A_T+K_S(s-u)+K_N(n-u)-F_TS_0]dt +\eta\sigma_{ST}\,dW_T.\end{split}\]

Here \(Y\) is physics.seconds_per_year. Time is measured in years. The separate factor of 100 converts mass-fraction derivatives to the scaled anomaly coordinates. This preserves the original MATLAB factor 100*3.15e7 without interpreting a simulation time unit as a century.

Bifurcation scenario¶

The forcing ramps relative to the simulation’s start time:

\[H(t)=\min\left[H_0+ \frac{H_{\rm fold}-H_0}{T/\text{param_end_multiplier}}(t-t_0), H_{\rm cap}\right].\]

The cap is \(H_{\rm fold}+\delta_{\rm cap}\) for forced runs and \(H_{\rm fold}-\delta_{\rm cap}\) for null runs. The configured fold is a calibrated marker. It is not automatically valid after changing physical coefficients.

Default critical parameter: 0.4236. Automatic markers follow the physical coefficients where supported; AMOC uses an explicitly calibrated marker.

Rate-induced scenario¶

The forcing is a smooth ramp followed by a plateau:

\[\begin{split}H(t)=\begin{cases} H_0+\Delta H/\cosh(rt),&t<0,\\ H_0+\Delta H,&t\ge0. \end{cases}\end{split}\]

Forced and null runs use r_fast and r_slow respectively. This schedule uses absolute time, with its plateau beginning at zero. The legacy simulator checks for transport below Q_collapse_threshold and uses the forcing’s zero-time point as its extraction marker. The marker and actual collapse time are distinct quantities.

Numerical and observation conventions¶

Both models integrate drift using RK4 with true midpoint forcing values in the new interface, then add independent Gaussian salinity increments. No positivity projection is applied to salinity anomalies. make_trajectory samples its initial state from the configured Gaussian mean and sigma_ic; explicit initial_state overrides that distribution. The legacy simulator retains the configured mean when no initial state is supplied.

Observed columns are \((Q,z_N,z_T)\). All physical constants are exposed through the shared immutable AMOCPhysics configuration, for example:

from tipbox.models import AMOC, AMOCPhysics

model = AMOC(physics=AMOCPhysics(K_N=1.8e6), sigma_ic=0)
result = model.make_trajectory(1000, noise=0.0, seed=42)

References: Alkhayuon et al. (2019) and Appendix A4 of Ritchie et al. (2023). The original MATLAB salt-balance implementation and plotting driver provide the code provenance and year convention.
